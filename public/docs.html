Card Battle API

ใช้ฟรี ไม่ต้องใช้ API key · ตอบเป็น JSON · เปิด CORS (เรียกจากเว็บอื่นได้) · จำกัด 120 requests/นาที/IP

Endpoints

MethodPathคำอธิบาย
GET/api/cardsรายการการ์ด (ค้นหา/กรอง/เรียง/แบ่งหน้า)
GET/api/cards/:idการ์ดใบเดียว เช่น SD01-001
POST/api/cards/batchส่ง {"ids":[...]} รับการ์ดหลายใบ (ใช้โหลดเด็คที่จัดไว้)
GET/api/decksรายชื่อเด็ค/ซีรีส์
GET/api/decks/:idเด็คพร้อมการ์ดทั้งหมด
GET/api/filtersค่าตัวกรองที่มี (type, element, rarity, keyword …)
GET/api/elementsสี + ไอคอน SVG ของแต่ละธาตุ
GET/images/:id.jpgรูปการ์ด

พารามิเตอร์ของ /api/cards

Queryตัวอย่าง
deck, type, element, rarity, rotation, tribe?type=Unit,Spell&element=ทอง (คั่นหลายค่าด้วย ,)
keyword?keyword=AUTO
q?q=ธอร์ ค้นชื่อ/รหัส/เอฟเฟกต์
costMin, costMax?costMax=3
sort, order?sort=cost&order=desc (id, name, type, cost, atk, def)
page, limit?page=2&limit=20 (limit สูงสุด 500)

ตัวอย่างใช้งาน (JavaScript)

const base = location.origin; // หรือ URL ของเว็บคุณ
const { data } = await fetch(base + "/api/cards?type=Unit&costMax=3").then(r => r.json());

// โหลดเด็คที่ผู้ใช้เซฟไว้
const deck = ["SD01-001","SD01-002","SD03-009SR"];
const res = await fetch(base + "/api/cards/batch", {
  method: "POST", headers: {"Content-Type":"application/json"},
  body: JSON.stringify({ ids: deck })
}).then(r => r.json());
