# Card Battle – Card Browser + API + Admin

📖 คู่มือฉบับเต็ม (ภาษาไทย): [MANUAL.md](MANUAL.md)

## รันในเครื่อง
```
npm install
ADMIN_PASSWORD=รหัสผ่านที่ต้องการ npm start
```
- หน้าเว็บ: `http://localhost:3000/`  ·  เอกสาร API: `/api/docs`
- หลังบ้าน: `http://localhost:3000/admin`  (ไม่ตั้ง `ADMIN_PASSWORD` = หลังบ้านปิดอยู่)

## ตัวแปรสภาพแวดล้อม (Environment variables)
| ชื่อ | จำเป็น | คำอธิบาย |
|---|---|---|
| `ADMIN_PASSWORD` | ถ้าจะใช้ /admin | รหัสผ่านเข้าหลังบ้าน (แนะนำยาว 12 ตัวขึ้นไป) |
| `DATA_DIR` | ถ้า deploy จริง | โฟลเดอร์บนดิสก์ถาวรของโฮสต์ เก็บข้อมูล/รูป/ข้อมูลสำรองที่แก้ผ่าน /admin เช่น `/var/data` |
| `ADMIN_SECRET` | ไม่จำเป็น | คีย์เซ็น session (ถ้าไม่ตั้ง ใช้ค่าที่สร้างจากรหัสผ่าน) |
| `PORT` | – | โฮสต์ส่วนใหญ่ตั้งให้เอง |

> ⚠ **สำคัญ:** ถ้าไม่ตั้ง `DATA_DIR` ข้อมูลที่แก้ผ่าน /admin จะถูกเขียนลงในโฟลเดอร์โค้ด
> บนโฮสต์ที่ระบบไฟล์ชั่วคราว (เช่น Render/Railway แพ็กเกจฟรี, Heroku) ข้อมูลเหล่านั้น **จะหายทุกครั้งที่ deploy ใหม่หรือรีสตาร์ท**
> ต้องผูก Persistent Disk / Volume แล้วตั้ง `DATA_DIR` ให้ชี้ไปที่ดิสก์นั้น
> ครั้งแรกระบบจะคัดลอกข้อมูลเริ่มต้นไปไว้ที่ `DATA_DIR` ให้เอง

## วิธีเพิ่มการ์ดผ่าน /admin
1. เข้า `/admin` ใส่รหัสผ่าน
2. แท็บ **นำเข้า Excel** → ดาวน์โหลดไฟล์ต้นแบบ (หรือ "ส่งออกการ์ดปัจจุบัน" แล้วเพิ่มแถว)
3. เลือกไฟล์ `.xlsx` / `.csv` → ระบบเดาการจับคู่คอลัมน์ให้ ปรับในช่อง dropdown ได้ (จำการตั้งค่าไว้ให้ครั้งหน้า)
4. หากต้องการนำเข้ารูปพร้อมกัน ให้เลือกหลายรูปในช่อง **เลือกรูปการ์ด** โดยตั้งชื่อไฟล์ตาม id ที่ Excel สร้าง เช่น `SD01-001.jpg` หรือ `SD03-009SR.png`
5. กด **ตรวจสอบก่อน** ระบบจะแสดงจำนวนการ์ดที่จะเพิ่ม/อัปเดตและรายการรูปที่จับคู่ได้ โดยยังไม่บันทึกอะไร
6. ตรวจผลแล้วกด **บันทึกเข้าระบบ** เพื่อบันทึกข้อมูล Excel และรูปที่จับคู่ได้ในรอบเดียว รูปที่ชื่อไม่ตรงกับ id จะไม่ถูกบันทึก
7. หากต้องการอัปโหลดรูปอย่างเดียวโดยไม่แก้ Excel ยังใช้แท็บ **รูปภาพ** ได้เหมือนเดิม

กฎของไฟล์ Excel: 1 แถว = 1 ใบ · จำเป็นต้องมี deck, no, name, type · ถ้ามีชีทชื่อ `decks` ระบบจะอ่านข้อมูลเด็คจากชีทนั้นให้ด้วย ·
การ์ดที่ id ตรงกับของเดิมจะถูกแทนที่ทั้งใบด้วยข้อมูลในไฟล์ · ข้อมูลจะถูกสำรองอัตโนมัติก่อนแก้ทุกครั้ง (กู้คืนได้ในแท็บ "สำรอง/กู้คืน")

## โครงสร้าง
```
server.js              เซิร์ฟเวอร์ + API สาธารณะ
admin/router.js        API หลังบ้าน (ล็อกอิน, นำเข้า, อัปโหลดรูป, สำรอง)
admin/index.html       หน้า /admin
lib/importer.js        จับคู่คอลัมน์ + ตรวจข้อมูลการ์ด
lib/xlsx.js            อ่าน/สร้างไฟล์ Excel
lib/store.js           โหลด/บันทึกข้อมูล รูป และข้อมูลสำรอง
data/*.json            ข้อมูลเริ่มต้น (การ์ด เด็ค ธาตุ)
public/                หน้าเว็บ + docs + รูปเริ่มต้น
```

## Deploy บน Render

มีไฟล์ `render.yaml` สำหรับ Render Blueprint: Web Service ใช้ `npm install` / `npm start`, health check ที่ `/api/health`, ตั้ง `DATA_DIR=/var/data` และ mount Persistent Disk ที่ `/var/data` (1GB) ให้ข้อมูลการ์ด รูป และ backups อยู่ข้ามการ deploy/restart ได้

1. Push โฟลเดอร์โปรเจกต์นี้ขึ้น GitHub
2. ใน Render เลือก **New → Blueprint** แล้วเลือก repository ที่มี `render.yaml`
3. กำหนดค่า `ADMIN_PASSWORD` เป็นรหัสผ่านที่เดายากเมื่อ Render ขอ และตรวจสอบ `ADMIN_SECRET` ที่ระบบสร้างให้
4. Deploy แล้วเปิด URL ที่ Render ให้ จากนั้นไป `/admin` และล็อกอิน

**ข้อควรทราบ:** Persistent Disk ใช้ได้กับ Web Service ที่เลือกแพ็กเกจรองรับ disk (Blueprint นี้กำหนด `starter` ไม่ใช่ Free) และผูกกับ service เดียวเท่านั้น อย่าลบ disk หากยังต้องการเก็บข้อมูล การตั้ง `DATA_DIR` อย่างเดียวโดยไม่มี disk ไม่ทำให้ข้อมูลถาวร

## ข้อจำกัดการอัปโหลดแบบชุด

ชื่อรูปต้องตรงกับ ID ที่เกิดจากคอลัมน์ deck/no/variant ใน Excel เช่น `SD01-001.jpg` และ `SD03-009SR.jpg`; รูป JPG/PNG/WEBP ขนาดไม่เกิน 5MB ต่อรูป เลือกได้สูงสุด 99 รูปต่อรอบรวมกับไฟล์ Excel ระบบตรวจสอบก่อนบันทึก แต่ถ้าการ์ดมี ID ไม่ตรงกับชื่อไฟล์ รูปนั้นจะแสดงคำเตือนและไม่บันทึก

## เพิ่มการ์ดทีละใบผ่านหน้าแอดมิน

1. เข้าหน้า `/admin` และล็อกอินด้วย `ADMIN_PASSWORD`
2. สร้างเด็ค/ซีรีส์ในแท็บ **เด็ค** ก่อน หากยังไม่มี
3. เปิดแท็บ **+ เพิ่มการ์ด 1 ใบ** แล้วกรอกเด็ค, เลขการ์ด, ชื่อ และประเภท (จำเป็น)
4. เวอร์ชันพิเศษเป็นข้อมูลเสริม เช่น `SR`; ระบบสร้างรหัสให้อัตโนมัติ เช่น `SD01-001SR`
5. กรอกค่าสถานะและเอฟเฟกต์ตามที่มีได้สูงสุด 5 รายการ แนบรูป JPG/PNG/WEBP ได้ (ไม่เกิน 5 MB)
6. กด **ตรวจสอบข้อมูล** เพื่อตรวจตัวอย่าง จากนั้นกด **ยืนยันและบันทึกการ์ด**

เลขการ์ดจะถูกเติมเลขศูนย์ด้านหน้าให้ครบอย่างน้อย 3 หลัก เช่น `1` กลายเป็น `001`. หากรหัสการ์ดมีอยู่แล้ว ระบบจะไม่สร้างรายการซ้ำ; ใช้การนำเข้า Excel เพื่ออัปเดตข้อมูลเดิมแทน
